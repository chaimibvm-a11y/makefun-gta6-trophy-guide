An offline guide and tracker for all 55 Grand Theft Auto VI PlayStation 5 trophies — 1 platinum, 2 gold, 6 silver and 46 bronze — built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty, $250 in USDC. Everything runs from the files in this repo; no account, no connection and no download is needed while you use it.

## Run it

Serve `app/` with any static server, then open it in your browser:

```sh
node serve.ts
```

Then open http://localhost:8080 — or use `npx serve app` instead. The guide works with the network off.

## What the guide has

- Every one of the 55 trophies with its official name, description and grade as PlayStation publishes them.
- A guide for each trophy, written for this entry, with the source of each fact named beside it.
- A roadmap to the platinum, in the order to earn the trophies.
- Every missable trophy flagged, so nothing gets locked out by accident.
- A checklist tracker: tick trophies off, progress saved in the browser (localStorage), export it to a file and import it back.
- Filters by kind (story, missable, collectibles, activities, online) and a spoiler setting that hides the names and descriptions of story trophies until they are earned.
